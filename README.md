# LINKTOWN

A minimal 3D multiplayer browser game.

## Features
- 3D multiplayer gameplay in the browser
- Built with Three.js (WebGPU-first, WebGL 2 fallback)
- Post-processing: MSAA HDR, optional ambient occlusion (GTAO), bloom, and tone mapping
- Graphics controls via URL params: `gfx` (low/medium/high), `gpu` (webgpu/webgl), `dyn` (adaptive scale), `debug=1` (overlay)
- Fast iteration with Vite + Vue
